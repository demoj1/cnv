## 0.9.2 — мост MCP лечит себя сам, снимок страницы при движущейся камере и любой ширине

### Исправлено

- **Мост MCP лечит сломанный процесс.** Electron в режиме node, запущенный пачкой, иногда
  остаётся с битыми подключениями (`ECONNABORTED`) навсегда: поток писем живёт, а инструменты
  отвечают «cnv не запущен». Теперь обёртка `cnv-mcp` берёт системный `node` первым, а мост,
  поймав такое, перерождается на тех же stdin/stdout и просит клиента перечитать
  инструменты — без перезапуска агента. В ошибке — настоящая причина.
- **`web_screenshot` не встаёт, если двигать холст.** Нода на время снимка держится в кадре,
  как бы ни ехала камера (раньше уезжала за экран — кадры кончались на середине), а на её
  месте — плашка «идёт снимок страницы…», а не пустота.
- **`web_screenshot width` шире ноды** больше не размножает узкую вёрстку по горизонтали: нода на
  время снимка расширяется до нужной ширины и потом возвращается к своей.

## 0.9.1 — MCP переживает старт cnv, снимок страницы целиком, Esc для агентов

### Новое

- **`terminal_send keys`** — клавиши по именам: `esc` (прервать агента), `ctrl+c`, `enter`,
  стрелки, `tab`… Раньше `\u001b` в тексте уходил буквами.

### Исправлено

- **MCP переживает занятый старт cnv.** Мост ждёт cnv и переподключается: повторяет запросы
  с бэкоффом ~25 с, адрес и токен перечитывает на каждой попытке. Не дождался — пустой
  сервер, а когда cnv ожил — `tools/list_changed` и поток писем, без `/mcp` и перезапуска.
  Раньше после перезапуска cnv часть агентов оставалась без холста (`ECONNABORTED`).
- **`web_screenshot` ноды за экраном** больше не висит, не повторяет куски и не путает
  масштаб: холст на время снимка ставит ноду в кадр (незаметно, камера на месте), вся высота
  снимается по экранам и склеивается.
- **Шрифт доски** — как у карточек: из настроек, «Aa» под доской задаёт свой размер и шрифт.

## 0.9.0 — канбан-доски, таймеры для агентов, снимок страницы за экраном

### Новое

- **Канбан-доски.** Дорожки (по умолчанию Backlog, In progress, Done) со своим скроллом,
  markdown-карточки в редакторе поверх холста. Карточки с холста перетаскиваются на доску и
  встраиваются, с доски на холст — снова обычные карточки. Агенты, соединённые с доской,
  получают письма о её событиях и управляют ей инструментом `board`.
- **Таймеры для агентов.** Кружок раз в N минут шлёт письмо агентам, соединённым с ним
  связью, и только когда агент свободен. На кружке — сколько осталось, ✎ — сообщение и
  интервал, ⏸ — пауза. Агенты заводят и правят таймеры сами: `create_node kind=timer`,
  `update_node every/message/paused`.
- **`web_screenshot` через DevTools:** снимает и ноду за экраном или на другом столе;
  `width` — ширина вёрстки, `full` — вся высота; камеру человека не трогает.

### Исправлено

- Письма агентам о связях иногда терялись: правка мимо истории (статус агента), а потом
  сохранение сходили за загрузку файла.
- MCP-мост агентов запускается электроном живого cnv, а не `.AppImage`: агенты не теряют
  холст при старте.
- Выход из cnv без SIGABRT.

- «+ роль» — только у агентов; у терминала и страницы роль видна, если задана.
- Портал: без крутящегося значка у заголовка.

## 0.7.0 — свёрнутые агенты, письма о связях, рамка портала

### Новое

- **Агента можно свернуть в кружок** — ◉ справа в шапке, ПКМ «Свернуть / развернуть
  агента» или `update_node collapsed`. В кружке значок (или инициалы), имя и роль; пока
  агент работает, кружок дышит цветом, прогресс — кольцом. Процесс живёт дальше, размер
  терминала не меняется. Двойной клик — развернуть.
- **Значок агента** — «Действия ▸ Значок агента…» или `update_node icon` (агент может сам).
- **`set_status`** — агент сообщает прогресс 0…100 и строку: видно в шапке и на кружке,
  мимо истории undo.
- **Агенту — письмо, когда меняются его связи и цвета:** провели или убрали стрелку,
  перекрасили связь, соседа или его карточку — через 3 с тишины одно письмо от cnv с
  `+` / `−` / `~` и кто правил. Кто правил сам — тому не пишем.
- **Портал** — вместо кругляхи бегущая градиентная рамка по краю карточки.
- **Подпись группы** — двойной клик по группе или F2.

### Изменено

- Агенту при создании через MCP имя не задать: имя даёт cnv, специальность — в `role`.

## 0.6.0 — письма мимо поля ввода, почта, камера человека

### Новое

- **Письма агентам не врезаются в твой ввод.** Claude Code получает их каналом (MCP
  channels): строка «← cnv: …», поле ввода не трогается. OpenCode — через свой HTTP API
  (запускается с `--port`). Остальным письмо вставляется, только когда поле ввода пусто:
  пока ты набираешь агенту текст, письма ждут в очереди и уходят по порядку. `agent_send`
  отвечает, как дошло: `via: channel | agent | terminal | queued`.
  Каналы Claude — dev-функция: при старте агента Claude Code спрашивает подтверждение;
  выключаются в «Настройки → Агенты».
- **Контракт плагина агента:** `mcpChannel`, `deliver(ctx, letter)`, `inputDraft(screen)` —
  как доставлять письма своему агенту ([docs/agent-plugins.md](docs/agent-plugins.md)).
- **После перезапуска cnv** каждый агент, продолживший разговор, получает «cnv
  перезапущен, версия X», а при новой версии — что в ней нового.
- **Камера — человека.** Пока ты водишь мышью, `zoom_to`, `switch_desktop` и команды вида
  от агентов камеру не двигают (`force=true` — по твоей просьбе); в описаниях — снимать
  через `screenshot ids/rect`.
- **Страница за краем экрана** будится для агента на месте и живёт 10 минут после его
  обращения — без `zoom_to`.
- **Почта переживает перезапуск cnv**, в шапке письма время, `inbox sent=true` и
  `thread=<id>`; `reply_to` на неизвестное письмо уходит без привязки с предупреждением.
- **`wait_reply`:** 60 с по умолчанию, `ids` — ждать ответа на любое из писем, один и тот
  же ответ дважды не отдаётся.
- `update_node append` / `edits` — дописать или поправить кусок карточки; `batch` удаляет
  связи; `web_eval` понимает `await`; в `connections` портала — версия той стороны;
  `remind_me` — напоминание через N минут.

## 0.5.3 — порталы: большие письма без ложных ошибок

### Исправлено

- **Большие письма через портал** (файлы в мегабайты) больше не отвечают ложной ошибкой
  таймаута, когда письмо на самом деле дошло: подтверждения ждём после отправки и дольше
  для больших писем. Не дождались — `unconfirmed` с просьбой не переотправлять, а не ошибка.
- **Порядок писем:** письма в портал уходят очередью — короткое не обгоняет большое.
- **Имена вложений с той стороны** — как у отправителя (скобки, пробелы), в папке письма.
- `read_message` своего отправленного через портал письма показывает вложения.
- В описании `agent_send` — лимит ~8 МБ через портал и точность больших чисел в `data`.

## 0.5.0 — порталы между cnv

### Новое

- **Порталы** — двери между двумя cnv на разных компьютерах: портал с одним ключом на обеих
  сторонах, знакомство через публичные Nostr-ретрансляторы, прямой WebRTC-канал. Доверие —
  по ключу устройства: первый раз человек пускает cnv той стороны, дальше он входит сам.
  Через портал — только разговор агентов, подключённых к нему стрелками: `connections`,
  `agent_send` с данными и файлами, `wait_reply`. Настройки «Порталы»: имя cnv, отпечаток,
  свои ретрансляторы. TURN пока нет: в сетях со строгим NAT портал показывает ошибку.

- **Огонёк к странице на `web_fetch`:** агент сходил на сайт, открытый страницей на холсте, —
  к ней летит огонёк, по стрелке или «по воздуху».
- **`perf_profile`** — замер живого cnv изнутри: кадры, долгие задачи, CPU-профиль
  renderer, нагрузка процессов Electron (включая GPU и страницы).

### Исправлено

- **Shift+Enter в терминале** — новая строка в поле ввода агента (Claude Code, Codex,
  OpenCode), а не отправка.

## 0.4.1 — импульсы по связям, снимки нод, хелперы web_eval

### Новое

- **Хелперы `web_eval`** — `web_helpers`: именованные функции агента в `window.cnv`,
  переживают навигацию.
- **Импульсы по связям:** агент обращается к соседу — пишет ему, читает его терминал,
  читает или правит страницу или карточку — и по стрелке между ними пробегает огонёк, от
  того, кто обратился, к тому, к кому. Видно, кто с кем сейчас разговаривает.
- **Снимок нод без сдвига камеры** — `screenshot ids=… | rect=…`: скрытое окно рисует только
  эти ноды (хоть на другом столе), терминалы — их текстом, страницы — их кадром.

## 0.4.0 — MCP для команды агентов, сессии, файлы

### Новое

- **Кнопки и панели нод — единым реестром** (`src/renderer/src/nodes/actions.ts`): действие
  регистрируется один раз и встаёт в шапку (терминал, веб-страница) или в панель под
  выделенной нодой (карточка, картинка, файл, PDF, группа).
- **Цвет у всех нод:** кружки в панели под нодой, а у терминала и браузера — точка в шапке
  с палитрой.
- **Клик по имени в шапке** терминала, агента и браузера — переименование; роль у браузера
  тоже задаётся кнопкой.
- **ПКМ-меню короче:** правка, имя и роль, остальное — в «Действия ▸» (Цвет, Порядок,
  Выравнивание, Группа — ещё уровнем глубже). По пустому холсту — «Создать ▸».
- **Меню окна — пять пунктов** (Файл, Правка, Создать, Вид, Справка) из того же дерева, что
  и ПКМ; столы — подменю «Вид ▸ Столы».

- **MCP для команды агентов** (по отзывам самих агентов): `find_nodes` — поиск по тексту,
  цвету, области, группе, связи; `batch` — много правок атомарно и одной записью в истории
  (ссылки `$ref`); почта — у `agent_send` id письма, вложения `data`/`files`, статус «занят»,
  `wait_reply`, `inbox`, `read_message`; `web_fetch` — HTTP с куками браузера без ноды;
  `layout` (grid, row, column, radial, tree), `check_overlaps`, `get_edges`, `get_subtree`;
  журнал правок `history` / `changed_since` и `restore` удалённого; `web_eval` с
  `script_file`, `max_chars`, `out_file`.
- **Сессии агентов:** «Продолжить сессию…» (⟲ в шапке агента и в списке агентов слева) —
  список прошлых разговоров в папке агента; MCP `update_node session_id`,
  `list_agent_sessions`. Обёртка `claude` в терминалах cnv: ручной `claude -r` сам
  получает холст. Смена имени или роли у работающего агента приходит ему в чат.
- **Файлы:** копия файла снаружи workspace следует за оригиналом (и кнопка «обновить» /
  «отвязать» в панели); не-картинки — компактной плашкой с иконкой типа.
- **Таблицы markdown** — с сеткой и шапкой; редактор карточки — тем же шрифтом, что и
  просмотр.

### Исправлено

- Стрелку внутри группы не удавалось выбрать — клик забирала группа.
- `update_node color=null` не снимал цвет у части клиентов MCP; соседа можно звать по части
  имени («Прасковья»), с подсказкой «может, ты про …».
- Стрелки в дереве выходили из верха родителя и резали соседей — стороны по умолчанию
  теперь идут через более широкий зазор.
- Вставка средней кнопкой под нагрузкой иногда проскакивала в терминал.

## 0.2.0 — агенты, MCP холста, рабочие столы

### Новое

- **Агенты Claude Code на холсте.** `Ctrl+Shift+A`, иконка ✦ в панели слева или ПКМ →
  «Агент». Терминал, в котором сразу запускается Claude Code. Нода помнит id сессии и
  папку: после перезапуска агент поднимается через `claude --resume` и продолжает тот же
  разговор.
- **MCP-сервер холста.** Каждый терминал и агент получает доступ к холсту и знает, где он
  запущен: `whoami`, `get_canvas`, `create_node`, `update_node`, связи, выделение, камера,
  `run_command` (любая команда меню), рабочие столы, сохранение. Для внешних клиентов есть
  `cnv-mcp`: `claude mcp add -s user cnv -- ~/.config/cnv/mcp/bin/cnv-mcp`.
- **Агенты общаются друг с другом.** `agent_send` — подписанное сообщение другому агенту,
  `terminal_read` / `terminal_send` — чтение и ввод в чужой терминал.
- **Имена.** У каждого терминала, агента и браузера есть уникальное весёлое имя вроде
  «Задумчивый Аркадий». По нему агенты находят друг друга. `F2` — переименовать.
- **Роли и связи.** Роль задаётся кнопкой в шапке терминала или через «Роль…» в меню.
  Она попадает агенту в системный промпт и видна в MCP. Стрелка между агентами — это
  команда: `connections` показывает, кто к тебе прицеплен и с какими ролями.
- **Браузер для агентов.** `web_read`, `web_eval`, `web_navigate`, `web_screenshot`,
  `screenshot` всего окна.
- **10 рабочих столов.** `Alt+1…0` — переключить, `Alt+Shift+цифра` — перенести туда
  выделенное. Работают и из терминала, и из веб-страницы. Агенты на всех столах живут
  одновременно, MCP видит все столы.
- **Панель создания слева.** Карточка, веб-страница, файл, терминал, агент. Клик — нода в
  центре экрана, перетаскивание — туда, где отпустил. Если что-то выделено, новая нода
  связывается с ним стрелкой: вытащил агента при выделенном тимлиде — он уже в команде.
- **Масштаб веб-страницы.** Кнопки `−` / `+` в шапке браузера, клик по проценту
  возвращает 100 %. Запоминается в `.canvas` для каждой страницы.
- **Шрифт карточек.** Панель шрифта и размера у текстовых карточек, размер по умолчанию —
  в настройках.
- **Пример команды агентов** — `examples/agent-team.canvas`: тимлид, разработчик и ревьюер
  с ролями и связями.

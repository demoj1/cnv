# Мини-редактор картинок (crop / поворот / маска по цвету)

Согласовано в grilling-сессии. Недеструктивно, параметры в `x-cnv.image` ноды-картинки.

## Схема `x-cnv.image`

```ts
{
  crop?:  { x, y, w, h },        // нормализовано 0..1 от ИСХОДНИКА
  rotate?: number,                // градусы, любой угол
  colorKeys?: [{ color, tolerance }],  // tolerance 0..1
  sized?: true                    // юзер сам менял размер → авто-пропорцию не трогаем
}
```

## Решения

- **Поворот** — произвольный, Shift→снап к 45°. Модель A: рамка выделения и 8 ручек
  поворачиваются вместе с картинкой (поворот-aware оверлей/ресайз/хит-тест, под условием
  `угол≠0`, только у картинок). Привязка/направляющие/стороны связей — по AABB повёрнутой
  ноды. Гизмо-кружок над верхним краем + кнопки 90° L/R.
- **Кроп** — под-режим: рамка кадра, вне затемнено, Enter/клик-мимо применяет, Esc
  отменяет; картинка на время кропа показывается неповёрнутой. Хранится в координатах
  исходника.
- **Маска по цвету** — пипетка (клик → цвет исходника) + список цветов-чипов + слайдер
  допуска. Обработка в Web Worker (`OffscreenCanvas`, transferable), дебаунс: превью по
  уменьшенной копии пока тянешь, полный проход на отпускании. Кэш по `файл+параметры`,
  лимит стороны ~2048.
- **Композиция** — исходник → маска(alpha) → кроп → поворот. Пипетка читает исходник.
- **UI** — выделил картинку → мини-тулбар (90° L/R, кроп, пипетка) + гизмо поворота.
  Авто-подгонка высоты молчит, как только есть `x-cnv.image`.
- **Obsidian** — показывает оригинал; недеструктивность важнее запекания.

## Порядок стройки

1. Ядро: `core/image-edit.ts` (схема + геометрия), unit-тесты. Рендер-композиция crop+rotate, переученная авто-пропорция.
2. Поворот: гизмо + Shift-снап + 90°; поворот-aware оверлей/ресайз/хит-тест (gated).
3. Кроп: под-режим с рамкой кадра.
4. Маска: worker-пайплайн, пипетка, чипы, слайдер.
